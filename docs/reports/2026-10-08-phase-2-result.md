# 2단계 운영 기준 확정 결과

2026-10-08 / 정책 확정·문서 검토 완료. 앱 구현 변경 없음.

사용자 ‘2단계운영기준으로 진행’에 따라 작업계약 초안의 권장안을 확정했다.

- 추가 과제: 기본 선택 복습, 교사가 필수 지정 가능.
- 완료: 필수 과제 전체 완료 기준. 선택 잔여 별도 표시, 미완료 귀가 알림 제외.
- 이월: 조교가 수행·남은 범위 기록, 담당교사가 다음 확인일 지정.
- 정정: 원본·사유·수정자·시각 보존, 집계는 유효한 최신 값 기준.
- 리포트: 승인본·근거 보존, 근거 정정 시 새 버전 재검토.

## 가상 사례 검토

1. 24점 통과 + 선택 복습 잔여: 필수 완료, 미완료 안내 없음.
2. 24점 통과 + 필수 복습 잔여 귀가: 이월, 교사 다음 확인일, 안내 초안 검토.
3. 23점 귀가: 기본 과제 이월, 안내 초안 검토.
4. 23→24점 정정: 점수 통과만으로 필수 추가 과제까지 완료시키지 않음. 필수 잔여 해소 여부에 따라 안내 취소 대상 또는 내용 갱신·재검토. 기존 발송 이력은 보존.
5. 승인 리포트 근거 정정: 기존 승인본 보존, 수정 필요와 새 버전 재검토.

표와 정책의 상태·담당자·알림 조건을 같은 에이전트가 대조했다. 코드 변경이 없어 앱 테스트는 반복하지 않았다. 3단계 교사 입력의 구현 순서·검증 사례·4단계 의존 사항을 별도 계획에 작성했다.

## 남은 상태

1단계 실제 UI 확인·사용자 인수는 미확인. 이번 운영 기준 채택을 1단계 인수로 간주하지 않음. 기존 앱은 여전히 추가 과제 완료를 요구하는 구현이며 이번 정책은 후속 단계에서 반영해야 함. 선택형 입력만 먼저 활성화해 조교 처리와 불일치시키지 않도록 의존 사항을 명시함.
