# 역할별 UI·UX 체험 개편

사용자 승인: 원장 상황판, 교사 빠른 기록·상담 준비, 조교 출근 브리핑·지시서 중심의 UI·UX를 체험 가능하게 변경.

## 체험 순서

1. 원장 상황판에서 신입생·재원 관심 학생의 확인하기를 열고 ‘내가 확인할게요’를 누릅니다.
2. 교사 역할로 바꾸어 같은 확인 상태를 확인합니다. 상담할 학생을 선택하고 상담 초안·근거를 펼쳐봅니다. 빠른 수업 기록은 기존 기록 저장으로 연결됩니다.
3. 조교 역할로 바꾸어 지난 근무 이후 변화를 보고 ‘인계 확인했어요’를 누릅니다. 학생 카드의 지시서를 열어 완료 기준·다음 과제·담당교사를 확인합니다.
4. 지시서의 객관식 채점 체험에서 다섯 답을 입력하고 정답수·오답 문항을 확인합니다.

## 반영 및 제한

- 가상 적응·관심 시나리오 5명, 등록·퇴원 월간 예시, 후속 업무 진행률. 실제 퇴원 예측·교사 평가·근태 연동 없음.
- 상담 초안은 REPORTABLE 기록을 분류. AI 생성 아님. 내부 전용 기록은 제외.
- 브리핑은 가상 마지막 근무일 9/28 이후의 현재 관리 대상 학생 기록 중 최근 최대 5건. 실제 근무일 추적 없음.
- 지시서 과제·진행·완료 기준은 현재 과제 데이터에서 표시. 지도 방법·시간은 체험 예시로 표시.
- 5문항 채점은 예시 입력값 비교. OCR·이미지 채점·학생 성적 자동 저장 없음.
- 확인 상태와 인계 확인은 기존 저장 처리로 보존. 저장 실패 시 이전 데이터 복원. 기존 데이터 무변환, 초기화 없음.

## 검증

구문, 모델, 9개 화면 템플릿, 기존 저장 복구 검사 통과. test-experience.cjs에서 후속 확인 저장 실패·재시도·재조회, 역할 간 상태 공유, 담당 범위 제한, 상담 내부 기록 제외, 지시서 기준, 채점 미입력·정오답·비저장, 인계 저장 실패·접기 검사 통과.

실제 브라우저 화면 배치와 클릭 검증은 기존 접근 권한 차단으로 수행하지 못함. 대체 DOM 검사와 구분함. 프로젝트 AGENTS.md의 필수 확인 잔여 시 완료 커밋 금지 기준에 따라 완료 커밋 보류. 이전 UI 개편 변경과 이번 변경 모두 로컬에 보존했으며 GitHub push·배포하지 않음.
