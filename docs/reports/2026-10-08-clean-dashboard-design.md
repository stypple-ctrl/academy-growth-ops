# 밝은 컬러 대시보드 디자인 적용 · 2026-10-08

사용자 ‘디자인 실제적용 진행’ 승인으로 구현. 기준은 사용자가 첨부한 교육 대시보드와 도서 대시보드 화면. Figma 내부 컴포넌트 직접 변환이나 픽셀 단위 재현이 아닌, 기존 기능에 맞춘 직접 구현이다.

## 변경

- index.html의 활성 테마를 macos-theme.css에서 clean-dashboard.css로 교체. 기존 파일 보관.
- 흰 사이드바와 상단 메뉴, 연회색 작업 배경, 얇은 테두리, 단순한 버튼. 유리/반투명 배경 효과 제거.
- 원장 상단: 주황 확인 전, 파랑 교사 확인 중, 노랑 신입생 적응, 연초록 후속 확인 완료. 기존 careScenarios와 필터에서 집계. 신입생은 다른 상태와 중복될 수 있음을 명시.
- 학생 카드: 흰 본문과 상태별 색상 헤더. 회색 대기, 파랑 학습중, 주황 확인대기, 연빨강 미완료, 연초록 완료. 이름·상태 텍스트·과제·행동 버튼을 유지. 학생의 임의 식별색보다 업무 상태색을 우선하며 data-tone 속성은 호환을 위해 유지.
- 교사 입력 상태·Enter 이동·관찰 보호 유지. 입력 화면 스타일을 새 테마로 이관.
- 1150px 이하에서는 원장 요약 2열, 650px 이하에서는 메뉴와 버튼·작업 영역이 좁은 화면에 맞게 배치되도록 CSS 작성. 실제 기기 검증은 미완료.

## 검증

node --check app.js, test-render.cjs, test-experience.cjs, test-input-ux.cjs, test-assignment-links.cjs, test-task-policy.cjs, npm test 통과. 저장 실패/재시도·역할별 업무·미저장 보호 포함. git diff --check 통과.

주요 신규 글자/배경 색상 7쌍의 계산상 대비 5.41:1 이상. 전체 합성 화면과 모든 상태의 실제 시각 접근성 검사라는 의미는 아님.

## 제한과 복구

브라우저 접근 제한을 우회하지 않았으며 실제 스크린샷·레이아웃·모바일·사용자 인수는 미완료. 필수 실제 UI 확인이 남아 전체 완료 커밋과 push는 보류. 저장 키/데이터/업무 로직 변경 없음(원장 상단 표시 템플릿만 변경). 새 라이브러리나 원본 키트 에셋 추가 없음. index.html의 테마 링크를 macos-theme.css로 되돌리면 이전 스타일로 전환 가능하나 원장 상단의 4개 요약 템플릿은 별도 변경이다.
