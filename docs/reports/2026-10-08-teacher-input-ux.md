# 교사 입력 UX 및 관찰 보호 · 2026-10-08

사용자 승인: 추가 12회 및 프론트엔드 개선 진행. 수행자 1명. 범위는 계약 잔여 관찰 보호와 교사 입력 화면의 첫 개선 묶음.

## 반영

- 관찰 입력 변경을 추적. 닫기/취소/Escape, 메뉴·학생 바로가기 등 다른 행동, 역할·교사·반 전환 전에 폐기 확인. 취소하면 현재 내용·선택·역할 유지.
- 저장 성공 후에는 추가 폐기 질문 없이 닫음. 저장 실패 시 dirty 상태와 입력 유지. 미저장 관찰이 있으면 수업 마감 차단.
- 관찰·점수 미저장 상태에서 beforeunload 경고 요청. 브라우저가 경고를 생략하거나 사용자가 새로고침을 확정하면 초안은 사라짐. 영구 초안 복구 기능은 아님.
- 교사 화면에 점수 입력→저장→필요한 관찰 순서를 표시. 학생별 미입력/예상 PASS·FAIL·미저장/범위 오류/오늘 저장된 시험 표시.
- 저장 상태는 학생의 오늘 최근 본시험에서 계산. 현재 입력이 있으면 저장된 과거 값 대신 미저장 상태를 우선 표시. 저장 실패는 완료로 표시하지 않음.
- Enter 다음 학생, Shift+Enter 이전 학생. 첫/마지막에서는 목록 밖으로 이동하지 않음. 한글 조합 중 키 입력 무시. 숫자 입력의 화살표 기본 동작 유지.
- macOS 테마 유지. 표의 포커스 행·오류 입력·저장 패널을 구분하고 모바일에서 버튼을 세로 배치. 선택 관찰 도구는 고정 떠 있는 영역 대신 일반 문서 흐름에 배치.

## 검증

test-input-ux.cjs에서 기존 관찰 취소 시 내용 소실을 먼저 재현하고 보완. 닫기 취소, Escape, 역할 변경 취소, 메뉴 이동, 태그 변경, 마감 차단, 새로고침 경고 요청, 저장 실패/재시도, 0점, 점수 상태, Enter/Shift+Enter 검사 통과.

모델·렌더 템플릿·명단 입력·시험 연결·선택 복습 정책·역할 체험·저장 회귀 검사 통과. 다른 학생/반으로 이동 취소 시 기록 대상 유지와 IME/목록 경계도 검사. 신규 주요 글자/배경 색상쌍의 계산상 대비는 6.44:1 이상이며 실제 합성된 화면 전체 대비 검사는 아님. 실제 브라우저 접근 제한을 우회하지 않았고, 시각 배치·모바일·포커스 이동·브라우저 confirm/beforeunload의 실제 표시는 검증하지 못함. 자동 테스트는 DOM 대체 환경이다.

## 남은 범위

조교 잔여 범위 기록/교사 다음 확인일, 정정 원본·사유·수정자·시각 이력, 승인 리포트 버전 보존, 원장·조교 화면 개선, 실제 UI 확인 및 사용자 인수. 이전 보고서의 관찰 보호 미구현 항목은 이번 코드 반영으로 갱신하되 실제 UI 확인 대기는 유지한다.

승인된 필수 검증이 남아 완료 커밋과 push는 보류. 기존 미커밋 변경을 보존함. 새 라이브러리·DB·실제 발송·보조 에이전트 없음.
