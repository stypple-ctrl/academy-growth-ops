# 업무 중심 UI·UX 개편

2026-10-07 · 사용자 선택 2번 승인 범위

## 반영 사항

- 공통: 흰 카드와 민트·연두 포인트, 절제된 그림자, 간결한 체험 모드 안내, 작은 화면에서 표·과제 보드 가로 스크롤.
- 원장: 미완료 귀가와 미해결 학습 이슈 학생을 먼저 표시하고 반별 수업 기록 바로가기를 함께 배치. 그래프·집계와 날짜 필터는 아래로 이동. 우선순위는 상태별 순서이며 위험도 평가가 아님.
- 교사: 수업 반 바로가기, 학생 명단 기반 관찰·시험·나머지 버튼, 선택 학생 수가 보이는 하단 기록 영역. 선택하지 않은 일괄 기록 버튼 비활성화.
- 조교: 확인대기 → 대기 → 학습중 → 미완료 순서. 완료 과제는 펼쳐볼 수 있도록 하단에 모음. 도움 정도·진행 상태 입력에 레이블 표시.
- 저장 키·데이터 구조·시험 기준·과제 완료 조건·발송 시뮬레이션 유지. 2단계 운영 정책 작업은 포함하지 않음.

## 검사 결과

`node --check app.js`, `node --check model.js`, `node test-model.cjs`, `node test-render.cjs`, `node test-storage.cjs` 통과.

새 바로가기가 기존 다중 선택을 해당 학생 1명으로 바꾸는지, 범위 밖 학생을 무시하는지, 과제 카드가 빠짐없이 한 번씩 표시되는지 검사함. 저장 실패 복구 및 기존 데이터 보존 검사도 통과함. DOM 대체 환경 검사이므로 실제 브라우저 검증을 대신하지 않음.

## 남은 확인

브라우저 접근이 저장된 권한 설정에 의해 차단되어 실제 화면 확인은 수행하지 못함. 데스크톱과 모바일 화면에서 글자·버튼 겹침, 표와 보드 스크롤, 학생별 입력창과 저장, 완료 과제 펼치기 확인 필요.

프로젝트 AGENTS.md의 “검증 실패나 계약상 필수 확인이 남으면 완료 커밋을 만들지 않는다” 지침에 따라 완료 커밋 보류. GitHub push·배포 없음. 변경은 로컬 작업 파일에 보존됨.
