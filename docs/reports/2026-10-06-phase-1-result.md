## 검증

- 변경 전 기존 모델·렌더 검사는 통과했다.
- 수정 전 새 회귀 검사는 미선택 사실 저장, 중복 인원, 저장 실패 복구에서 각각 예상대로 실패했다.
- 수정 후 모델·렌더·저장 회귀 검사가 통과했다.
- 저장 호출 지점을 같은 에이전트가 후속 검토했다. 본시험 PASS/FAIL, 과제 지정·재시험, 설정, 알림 승인/모의 발송, 리포트 저장·승인·재생성, 초기화, 조교 선택, Case 상태·등록 경로를 확인했다.
- 저장 실패 후 재시도에서 중복 사건을 만들지 않고, 저장 버튼이 없는 선택 항목은 오류 안내의 ‘다시 저장’으로 재시도할 수 있다.
- 기존 데이터로 앱을 구성했을 때 기록과 localStorage 원문이 바뀌지 않는 검사를 통과했다.
- 실제 사용자 브라우저의 저장 데이터에는 접근하거나 초기화하지 않았다. 저장 키 `ieum-demo-v1`와 version 1을 유지했다.
- 테스트는 Node.js 및 DOM 대체 환경이다. 실제 브라우저 접근은 이전에 저장된 권한으로 차단되어 있어 이번에는 우회하거나 동일 접근을 반복하지 않았다. 화면 배치·클릭·실사용 시간은 미검증이다.

1. 기존 체험판 화면을 새로고침한다. 같은 브라우저·같은 주소를 사용하며 초기화는 하지 않는다.
