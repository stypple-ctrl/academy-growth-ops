# 이음 · 학생 성장관리 체험판

첨부 PRD v1.1의 협업 흐름을 체험하는 로컬 웹 앱입니다. 외부 패키지 설치 없이 실행합니다.

## 실행

이 폴더에서 `python3 -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173 접속.

## 체험 순서

1. 상단 역할을 교사로 변경 → 수업 기록 → 김민수 선택 → 단어시험 21개 입력.
2. FAIL 후 제안되는 나머지 지정 저장.
3. 상단 역할을 조교로 변경 → 대기 카드 입실 → 정답수 24 입력 → 재시험 결과 저장.
4. 자동 표시되는 Secondary 과제를 완료하거나 미완료 귀가 처리.
5. 원장/교사 역할에서 학생 360과 학부모 알림 검토 확인.
6. 월말리포트의 2026-09 샘플 또는 2026-10 새 기록을 확인하고 수정 → 승인 → 인쇄/PDF.

## 범위와 제한

- 가상 학생 48명, 반 6개, 담임 3명 + 원어민 1명, 나머지 카드 10개.
- 브라우저 localStorage 저장 및 같은 브라우저 탭 간 동기화. DB·인증·다른 기기 간 공유 없음.
- 역할 선택은 화면 시뮬레이션이며 보안상 접근제어가 아님.
- 데모 기준일은 2026-10-01. 본시험/재시험 30문항 80% PASS, 설정 변경 가능.
- 월말리포트는 공유용 이벤트를 월별 집계한 템플릿 초안. AI 호출 없음.
- 문자 발송은 시뮬레이션. PDF는 브라우저 인쇄의 PDF 저장 사용.
- 학생/반/사용자 CRUD, 음성메모, 고급 패턴 탐지와 자동 셔틀 스케줄은 후속 구현 범위.
- 경과 45분 경고는 화면 갱신 때 계산. 데이터는 설정에서 초기화 가능.

`node test-model.cjs`

## 1단계 개선 (2026-10-06)

- 조교의 도움 정도·진행 상태는 ‘미확인’으로 시작합니다. 선택한 사실만 결과 기록에 포함합니다. 기존 관찰 기록은 변경하지 않습니다.
- 나머지 대상은 고유 학생 인원으로 집계하고, 과제 건수·완료율은 과제 기준으로 표시합니다.
- 화면에서 기본 과제 / 추가 과제 / 미해결 용어를 사용하고 현재 지표와 선택 기간 기록을 구분합니다.
- 저장 실패 시 입력과 선택을 유지하고 미저장 데이터 변경을 복구합니다. 원래 저장 버튼을 다시 누르거나, 자동 저장 선택 항목의 오류 안내에서 ‘다시 저장’을 누르면 됩니다.
- localStorage 키와 데이터 버전은 유지합니다. 이 변경 때문에 ‘데모 데이터 초기화’를 누를 필요가 없습니다.

검사 명령: `node test-model.cjs`, `node test-render.cjs`, `node test-storage.cjs`.
DOM 대체 환경의 검사이며 실제 브라우저 클릭·배치 검증을 대신하지 않습니다.
